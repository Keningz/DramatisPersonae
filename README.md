# 人物谱 · Dramatis Personae

经典作品人物关系图网站。每本书（或每部剧）一张关系图，中英双语；同一人物出现在几本书里时，互相链接。

目前收录荷马的《奥德赛》《伊利亚特》、维吉尔的《埃涅阿斯纪》、《西游记》、《三国演义》、《红楼梦》，以及电视剧《权力的游戏》。

## 目录

在 GitHub 仓库里，`site/` 的页面直接放在仓库根目录（GitHub Pages 从 main 分支根目录发布：https://keningz.github.io/DramatisPersonae/ ）。重建后把 `site/*.html` 复制到根目录再提交即可。

```

  index.html       书目首页（含“在几部书里都出现的人”）
  odyssey.html     奥德赛人物谱（环形布局，奥德修斯居中）
  iliad.html       伊利亚特人物谱（动态布局，点谁谁到中央）
  aeneid.html      埃涅阿斯纪人物谱（动态布局，全景按故事从左到右排开）
  journey.html     西游记人物谱（动态布局，天庭、灵山在上，取经五众居中，路上的人和妖按回目排开）
  sanguo.html      三国演义人物谱（动态布局加回目时间轴：拖到哪一回，就显示那一回的人物、阵营与关系）

  odyssey/         奥德赛：人物与关系数据、英文文本、环形布局、陶瓶小像、页面样式与脚本
  iliad/           伊利亚特：人物与关系数据（中英）、全景坐标、新增小像
  aeneid/          埃涅阿斯纪：人物与关系数据（中英）、壁画风小像、全景布局优化、页面样式
  journey/         西游记：人物与关系数据（中英、拼音、回目）、木刻绣像风小像、全景布局优化、页面样式
```

`site/` 里的页面都自带字体、小像和数据，放到国内的服务器上也能正常打开。唯一的外部请求是谷歌分析（见下）。

## 访问统计

`site/` 的每个页面（GitHub Pages 上的版本）在 `<head>` 里带谷歌分析的统计代码，衡量 ID 是 `G-DTTJVF6E9D`，写在 `src/common/dpsite.py` 的 `GA_ID`；改成 `''` 再重建就不带统计代码。`artifact/`（claude.ai 版）不带。

- 统计脚本是异步加载的：在打不开谷歌的地方（包括中国大陆），页面照常使用，只是这些访问不会被计入，所以国内访客会少算。
- 页面切换人物、语言、回目时不改网址，因此每打开一次页面只算一次浏览。
- 本地双击打开 `site/` 里的页面时也可能发出统计；如果混进了数据，可以在谷歌分析后台按主机名筛掉。

## 重建

```
python3 src/build_all.py
```

需要 Python 3.9 或以上，不需要安装第三方库。会重新生成 `site/`（自托管用）和 `artifact/`（发布到 claude.ai 用，额外加载谷歌字体 Noto Serif SC）。

埃涅阿斯纪和西游记的全景坐标存在各自文件夹的 `overview.json`。改了人物或关系后，可以运行 `python3 src/aeneid/overview_layout.py` 或 `python3 src/journey/overview_layout.py` 重新排布：它在每个区域（如众神两侧、特洛伊、意大利；或天庭、灵山、取经路前中后段）内部挑位置，尽量减少交叉和穿过别人的连线，大约一分钟。

## 三国演义的时间轴

- 每个人物有 `debut`（登场回）、`dies`（去世回，或书中交代其死讯的回）、怎样去世（`DEATH`：被杀、被处死、自尽、伤重而死等算死于非命，病逝、善终不算）和 `camps`（阵营变化，`[(回, 阵营)]`，从该回结束时起算）。阵营有汉室、群雄·在野、魏、蜀、吴、晋，小像边框按此时所属的阵营着色。
- 每段关系有若干 `phases`，按回目排列：`P(回, 类型, 中文标签, 中文说明, 英文标签, 英文说明, 出处)`。关系在第一个阶段的回目出现，此后每到一个新阶段，类型与标签随之改变（例如关羽与曹操：土山约三事 → 挂印封金 → 过五关 → 华容道 → 威震华夏 → 厚葬）。
- 滑块停在第 N 回时：还没登场的人淡去，已去世的人变灰（死于非命的另加 ✕；病逝或善终的不打叉），连线只显示到这一回为止已经发生的关系，本回新出现或改变的关系加粗。最右端“全书”显示全部人物与关系的最终状态。
- 全景按势力分成四条横带（汉室·群雄、曹魏、蜀汉、东吴），每人排在登场那一回的位置；九个段落（黄巾、董卓、群雄、官渡、赤壁、荆益、夷陵、北伐、归晋）的宽度一半平均分配、一半按登场人数分配。
- 链接可以带回目：`sanguo.html#zh.caocao.c21` 表示以中文打开、跳到第二十一回并以曹操为中心。

## 红楼梦的家谱与后四十回

- 数据格式与三国演义相同（`debut`、`dies`、`DEATH`、`camps`、分阶段关系），另有：`bio` 只写前八十回的事，`late` 写第八十一至一百二十回；`camps` 可以带说明，如 `(79, "out", "嫁给孙绍祖", "Married to Sun Shaozu")`；`born` 是嫁进来的女子的娘家；`verses` 是太虚幻境里的判词、红楼梦曲等。`data_hl.py` 会检查 `bio` 不引后四十回、`late` 不引前八十回，关系不早于人物登场。
- “后四十回”开关默认关闭（记在浏览器里）：关闭时滑块只到第八十回，八十回以后的死亡、府第变化、关系阶段、`late` 传记一概不显示；打开后续书的内容都标“续”。链接里加 `c97` 这类后四十回的回目会自动打开开关，也可以用 `full`/`cut` 强制开关，例如 `honglou.html#zh.daiyu.full`。
- 小像边框是此时所在的府第或家族：宁国府、荣国府、宫中、林、史、王、薛、府外、空门·方外。来做客的姑娘和她们的丫鬟保留娘家的颜色（黛玉林家、宝钗薛家、湘云史家）。
- 全景是一张家谱，坐标写在 `build_hl.py` 的 `OV`：横向史家在左，宁、荣居中，林、王、薛在右；纵向四行按辈分（代、文、玉、草）；下面两排丫鬟仆妇站在各自主子底下，最下一排是府外与方外，左上角是太虚幻境。贾代化、贾代善、贾敏、贾珠、薛公等不在图中的人画成虚线小圈，只为把家谱连起来。
- 死于非命（自尽、被害、中毒、受虐、中邪暴亡）才打 ✕；病故、寿终、难产不打叉。秦可卿依程高本正文作病逝，判词卡片里说明了“悬梁自缢”的画。

## 权力的游戏的剧集时间轴与防剧透

- 只收 HBO 电视剧（2011—2019，八季七十三集）的情节；与原著小说不同的地方一律以电视剧为准。以后若做小说版，另开一页。
- 集数在数据里写成 `S3E9` 这样的常量（`episodes_got.py` 把第 1—73 集逐一定义成 `S1E1` … `S8E6`）；文字里的 `(S3E9)` 会变成可点的集数按钮。
- **防剧透**：每个人的 `subs`（随剧情变化的身份说明）和 `bios`（分段经历）都标明从哪一集起显示。滑块停在某一集时，人物卡片里的经历、阵营变化、死亡、关系史都只显示到这一集，后面还有几段会写“往后还有 N 段”。`data_got.py` 会检查每段经历引用的集数不晚于它显示的那一集。浏览器会记住滑块停在哪一集（`localStorage` 的 `dp-t-got`）；链接里加 `s3e9` 可以直接跳到某一集，加 `all` 回到全剧。
- 剧集开始前就已死去的人（莱安娜、雷加、疯王、琼恩·艾林）写 `dies=PRE`，从首次被提到起就是灰色；琼恩在第五季末被杀、第六季第二集复活，用 `down` 表示中间那一段。
- 全景大致按地理排开：长城以北在最上，然后是守夜人、北境，再往南是铁群岛、河间、谷地、龙石岛，然后是河湾、君临、风暴地、多恩；坦格利安家与厄索斯在右边。各家族在自己的地盘上画成小家谱；家谱线可以按集数出现或消失（`data-from` / `data-until`），例如琼恩“艾德的私生子”那条虚线到第六季第十集为止，之后换成莱安娜之子。
- 外圈颜色是此时站在哪一边（`camps`，共十六种，“无所归属”是虚线）；印章底色是出身家族的颜色。
- 不画人物肖像和家族纹章（剧集的版权形象），每个人是一枚印章：家族颜色、名字的首字（中文是第一个字，英文是第一个字母，写在印章下方），中间是表示此时身份的通用小图案。
- **印章图案**（`seals_got.py`）：`GLYPHS` 是 29 个自己画的通用图案（王冠、城堡、手、剑、矛、弓、斧、学士链、书、钱币、鸟、火焰、七角星、船、树、雪花、马、草药、面具、断链、羽毛笔、盾、锤、酒杯、天平、火炬、花、眼、锁），在 100×100 的框里用 `currentColor` 画，颜色跟随家族的字色。`EMBLEMS` 给每个人按集数排好身份变化，第一项必须在登场那一集，例如琼恩是剑→火炬（守夜人）→斧（混入野人）→火炬→剑→王冠（S6E10 北境之王）→剑→火炬。全剧视图用持有最久的图案，个别人在 `HOME` 里手动指定（布兰是眼，提利昂是手）。图案只表示身份，不画任何家族纹章里的动物（不画龙、冰原狼、狮子等）。`data_got.py` 检查每人都有图案、首项在登场集、按集数递增、相邻不重复、不晚于死亡。人物一览和首页卡片用登场时的图案，不剧透。
- 每段关系与每个人物的集数都经过逐条核对（以 Game of Thrones Wiki、维基百科各集条目为准），人名与集名的中文译法参照冰与火之歌中文维基；五个维基上没有中文名的集名用通行译法。

## 加一本新书

1. 在 `src/` 下新建文件夹，写人物数据 `NODES`（每人一个英文小写 `id`）和关系数据 `EDGES`，格式参照 `src/aeneid/data_ae.py`。
2. 同一个人物在不同书里用**同一个 id**（例如 `odysseus`），跨书链接会自动生成。名字不同的（罗马神名），加 `same_as` 指向希腊名的 id，例如朱庇特写 `same_as="zeus"`。
3. 在 `src/common/dpsite.py` 的 `BOOKS` 里登记这本书（文件名、中英文书名、人物数据文件、`names` 是希腊名、罗马名还是中文名）。导航会自动出现这本书。
4. 想要“点谁谁到中央”的动态图，就用 `src/common/dynamic.js` 与 `dynamic.css`，照 `src/aeneid/build_ae.py` 写构建脚本；书名、环的大小、每人朝向都通过页面里的 `DATA` 传给引擎。
5. 在 `src/index/build_index.py` 加书卡片的简介和小像，在 `src/build_all.py` 加上它的构建脚本。

## 约定

- **小像边框**：神＝金色（外加细光环），凡人＝陶红，怪物＝铜绿，半神（神或仙女之子，西游记里是神佛转世为人）＝半金半陶红，亦神亦妖（西游记的悟空、八戒、沙僧、白龙马、黄袍怪）＝半金半铜绿。
- **小像画法**：权力的游戏不画肖像，用家族颜色的印章加身份图案代替。红楼梦仿清代孙温《全本红楼梦》图的工笔重彩：细墨线，石青、石绿、朱砂、泥金平涂，女子挽髻插簪、多披云肩，男子戴清代冠帽，每人配一件标志物（黛玉的花锄、宝钗的金锁、晴雯的撕扇）。荷马的人物仿古希腊陶瓶画：红绘画神与凡人，黑绘画怪物，白底线描画冥府亡魂。维吉尔的人物仿庞贝壁画：神以庞贝红为底、带淡色光轮，凡人以绿为底，怪物以赭黄为底，亡魂以灰蓝淡彩。几本书共有的人物用同一套线稿，换上各自的画风。西游记仿明刊本木刻绣像：墨线勾勒，米黄纸底，淡彩点染，神佛头后有圆光，妖怪的纸色略深。三国演义仿京剧脸谱：关羽的红脸、曹操的白脸、张飞的黑十字门等依戏曲传统；没有固定脸谱的人物画作俊扮，靠髯口、盔头、服装区分。
- **名字**：希腊文名写在荷马的人物旁；维吉尔的人物写拉丁名，用罗马碑铭式大写（U 写作 V，如 IVPPITER）；西游记、三国演义、红楼梦的人物写带声调的拼音；权力的游戏的人物写英文全名。
- **连线四类**：亲缘（实线深灰）、友助（实线蓝）、敌对（红色虚线）、纠葛（紫色点线）。西游记另有第五类“主从”（橙色点划线）：神佛与坐骑、童子、宠物、下属，数据里的类型名是 `mas`，起点是主人。三国演义沿用这一类型作“君臣”：主公与臣属、主将与部将。三国演义的小像边框不分神人，而是表示此时所属的阵营。红楼梦把 `mas` 用作“主仆”，另加第六类“情缘”（`love`，玫红实线）：爱慕、私情与婚约；“友助”称“知交”，“敌对”称“构陷”。权力的游戏沿用这六类，`mas` 称“效忠”（主君与臣属、雇主与佣兵、师徒），“友助”称“友盟”，“敌对”称“仇敌”。
- **出处**：每段关系都注明卷数（西游记注明回目，依百回本；三国演义依毛宗岗评本一百二十回；红楼梦依一百二十回程高本系统的通行文本，引文以此本为准，判词与曲子用通行本文字；权力的游戏注明季与集，如 S3E9）。存疑的诗行（如《埃涅阿斯纪》卷二的海伦一段）在文中注明。
- **链接格式**：`aeneid.html#en.jupiter` 表示以英文打开埃涅阿斯纪并定位到朱庇特；`#zh`、`#en` 单独使用只切换语言。
